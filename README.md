# 小川商店 育成ノート

GitHub Pages上の社員・アルバイト別育成アプリ。Supabase Authと共有データベースに接続しています。

## 利用方法

Supabase Authentication → Usersで作成したメールアドレスとパスワードでログインします。ogawa_membersのroleがeditorなら閲覧・登録・評価更新、viewerなら閲覧のみです。未登録者はアクセスできません。権限はアプリ画面だけでなく、SupabaseのRLSで制御します。

- 社員とアルバイトは専用ページと別集計。
- 対象外（評価値4）は習得率の分母から除外。全業務対象外は—表示。
- 画面表示中は15秒ごとに共有データを取得。評価・追加ダイアログを開いている間は自動取得を止めます。
- 同時編集はupdated_atの一致で確認し、古いデータによる上書きを拒否します。
- 通信エラー時に保存成功とは表示しません。
- 旧版のブラウザ保存データは削除せず残していますが、自動移行しません。共有データは新規登録から始まります。
- 端末のタブを閉じるとログインセッションは終了します。共有端末では必ずログアウトしてください。

アプリの公開URLやPublishable keyだけではデータを閲覧できません。ブラウザ用コードにSecret keyやservice_role keyを入れないでください。
