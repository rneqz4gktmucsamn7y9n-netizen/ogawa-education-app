# 小川商店 育成ノート

Supabaseのメール確認を終えた登録者は全員、社員・アルバイトの両ページを閲覧・編集できます。承認はありません。

初期管理者だけが登録者一覧とアカウント削除を使用できます。自身と他の管理者は削除不可。削除はログインアカウントと編集権限を削除し、スタッフの習得データは保持します。再登録を永久に禁止する仕組みではありません。

## データベース設定

既存のogawa_membersとogawa_staff、およびRLS設定に加え、database/open-registration.sqlをSupabase SQL Editorで実行してください。前方式のapproval-setup.sqlは使用しません。

管理者権限はogawa_adminsで管理し、ブラウザからの直接追加・更新は許可しません。登録者一覧と削除RPCは管理者を検証します。通常の登録者は自分の編集権限だけを取得できます。未確認・未ログイン・削除済みアカウントは取得不可。

データ取得は15秒ごと。同時編集では更新日時を確認し、古い情報による上書きを拒否します。「対象外」は習得率の分母から除きます。全業務対象外は—表示です。

公開コードにはPublishable keyのみを使用します。Secret keyやservice_role keyを追加しないでください。旧端末内データは自動移行しません。
